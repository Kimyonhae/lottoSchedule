# 🎯 로또일정 LottoSchedule

**로또일정**은 사용자가 구매한 로또 번호를 앱에 등록해두고, 매주 발표되는 당첨 결과에 따라  
**간편하게 당첨 여부를 확인하고 알림을 받아볼 수 있는** 시간을 절약해주는 라이프스타일 앱입니다.

---

## 📱 주요 기능

- ✅ **로또 등록 기능**
  - QR 코드 스캔을 통해 간편하게 로또 번호를 인식하여 저장
  - 구매한 로또 티켓 정보를 앱에 보관 (※ 실물 복권은 반드시 보관하세요!)

- 🔔 **자동 알림 기능**
  - 매주 **일요일 오전 8시**, 등록된 번호의 당첨 여부를 알림으로 전달
  - 당첨 여부를 **로또 결과에서 확인**

- 📊 **로또 내역 관리**
  - 내가 보유한 로또 번호들을 저장하면서 **수집 가능**
  - 회차에 따라 **구분된 목록으로 보기**

---

## 🧩 앱 목적

로또를 사고 나서 추첨일과 발표 시간을 기억하고 챙기기란 쉽지 않습니다.  
**로또일정**은 Apple의 ‘일기’ 앱에서 영감을 받아, 로또 구매자들이 더욱 편리하게 복권을 관리하고  
당첨 여부를 놓치지 않도록 돕기 위해 만들어졌습니다.

---

## 🛠 기술 스택

- `iOS`: Swift, UIKit
- `Core Data`: 로또 번호 영구 저장
- `UserNotifications`: 주기적인 알림 기능
- `SwiftSoup`: QR 스캔 데이터 전달 및 추첨 여부 확인

---

## ⏰ 향후 계획

- ✅ 이미 추첨이 끝난 복권을 스캔하면 즉시 당첨 여부를 확인할 수 있는 기능 추가 예정
- ✅ 로또 수정하기
- ✅ 검색기능
- ✅ 앱스토어에 배포하여 사용자 피드백 수집 및 개선
